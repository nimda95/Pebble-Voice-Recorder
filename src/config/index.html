Transcription

Service
Works with OpenAI and compatible servers (faster-whisper-server / Speaches, LocalAI, whisper.cpp, Groq). Models that return segments (such as whisper-1) give real timestamps; others are spread over the recording.
Phones can't open Wyoming's raw TCP port, so this goes through Home Assistant's speech-to-text API, which fronts your Wyoming faster-whisper. Audio is split at pauses, so each line gets its real start time.
